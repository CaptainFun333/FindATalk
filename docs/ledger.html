Style guide

FindATalk's visual language: a well-kept parlor bookshelf, not a tech dashboard — warm paper tones, a brass-and-burgundy accent pair, serif type doing the heavy lifting. Transcribed from the shipping stylesheet at docs/index.html.

Palettes

Two independent settings — Appearance (Light/Dark/System) and Palette (Brass/Rose/Slate/Sage, plus a hidden sixth, Celestial) — combine into ten live themes. Brass is the default and reference palette; the others are deliberate variations on it, not separate brands.

accent-a is the palette's "odd color out" (eyebrows, focus rings) — deliberately outside the hue family ink/ink-soft already occupy, so it never blends into secondary text. accent-b (links, text accents) lightens in dark mode to stay legible. accent-fill (button backgrounds) stays dark/deep in both themes on purpose — reusing accent-b there would make dark-mode buttons pale and hard to read. ink is pure white in every dark theme; only ink-soft carries the palette's hue in the dark.

Typography

Three families, each with a fixed job:

  • Source Serif 4 — reading surfaces: talk text, page titles. The "book" of the app.
  • Lora — card/modal headings, and the search input itself (the one control set in serif, not Inter — search is a reading action, not a form field).
  • Inter — everything else: buttons, labels, list rows, chips. Uppercase eyebrow labels are always Inter, 600 weight, uppercase, 0.08–0.14em letter-spacing.

Shape & elevation

  • Default radius 4px — buttons, inputs, cards. Reach for it first.
  • Fully-rounded pills (999px) mark filter chips and status badges; 50% is reserved for circular elements.
  • One soft shadow style only, tinted with the palette's own ink at low alpha (never pure black) — no second "card shadow." Use a border instead when a surface needs separation but not lift.
